# 이메일 변경 후 회차 동기화 체크리스트

이 문서는 **학생/선생님 이메일을 바꾼 뒤** 캘린더/Meet가 정상인지 확인하는 운영 체크리스트입니다.

## 0) 사전 확인

- 관리자 페이지에서 학생/선생님 이메일 저장 완료
- 저장 후 학생 상세(`smain`)에서 이메일이 새 값으로 보이는지 확인

## 1) 선생님 캘린더 동기화

- 선생님 계정으로 로그인
- 해당 학생 `smain` 화면에서 `회차 동기화` 클릭
- 결과 문구에 `오류 0개` 또는 실패 원인 확인
- Google Calendar에서 `옥진수학` 캘린더만 확인
- 이번 주 회차 1~2개를 열어서 `참석자`에 학생 이메일이 들어갔는지 확인
- Meet 링크가 열리는지 확인

## 2) 학생 캘린더 동기화

- 학생 계정으로 로그인
- 같은 학생 `smain` 화면에서 `회차 동기화` 클릭
- 결과 문구 확인
- Google Calendar에서 학생 계정의 `옥진수학` 캘린더 확인
- 회차 시간/날짜와 앱 화면이 같은지 확인

## 3) 앱 화면 검증

- `a/smain`, `t/smain`, `s/smain`에서 같은 학생의 예정 수업 시간/회차가 같은지 확인
- 회차 상세에서 `수업 버튼(Meet 이동)`이 정상 동작하는지 확인

## 4) 장애 시 즉시 점검

- `401` 오류:
  - 홈에서 로그아웃 -> 다시 로그인(권한 동의 포함)
- `403 insufficient scopes`:
  - Google Cloud Console에서 Calendar API/권한 범위 설정 재확인
- 생성은 되는데 다른 캘린더에 생김:
  - 로그인한 계정이 담당 선생님 계정인지 확인

## 5) 완료 기준

- 선생님/학생 각각 `옥진수학` 캘린더에서 회차 이벤트 확인
- Meet 링크 열림
- 앱의 예정 수업과 캘린더 시간이 일치
- 동기화 결과에 치명 오류 없음
