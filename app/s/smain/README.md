# /s/smain 페이지 정리

## 페이지 한 줄 설명
학생 본인이 자신의 학생 허브를 보는 메인 페이지입니다.

## 화면 구조
- `StudentMainClient(role="s")`
- 내부에서 로그인 이메일과 일치하는 학생을 자동 선택하려고 시도합니다.
- 선택된 학생은 `StudentHubCore(role="s")`로 렌더링됩니다.

## 학생 화면에서 보이는 범위
- 기본 정보 확인
- 예정 수업 리스트 확인
- 수업 목록 이동

## 학생 화면에서 숨겨지는 기능
- 정보 편집/시간 변경 버튼
- 상담 생성/수정 버튼
- 회차 동기화/사물함 정리
- 수납 패널
- 학부모 연락처 표시

## 권한
- `/s/*` 경로이므로 학생/선생님/관리자 계정이 정책상 접근 가능합니다.
- 단, 실제 기능 노출은 role=`s` 정책으로 제한됩니다.
