# /lib/lectures 페이지 정리

## 페이지 한 줄 설명
강의 폴더/강의 항목을 관리하는 "강의 저장소" 페이지입니다.

## 화면에서 할 수 있는 일
- 폴더 추가/이름수정/순서변경/삭제
- 강의 추가/수정/순서변경/삭제
- 강의 고유코드 복사
- 고유코드로 다른 폴더 강의 불러오기

## 저장 방식
- 로컬에서 먼저 수정 상태(`isDirty`)를 관리합니다.
- 상단 `☁️ 클라우드에 지금 저장` 버튼으로 서버에 반영합니다.
- 저장하지 않고 나가면 `beforeunload` 경고가 뜹니다.

## 동기화 규칙
- 페이지 진입 시 원격 스냅샷을 불러옵니다.
- 로컬에만 강의가 있고 원격이 비어있으면 원격 복구 업로드를 시도합니다.
- 저장 성공 시 `마지막 클라우드 저장 시간`이 갱신됩니다.

## 회차 화면과 연결
- 여기서 만든 강의 목록은 회차 상세(`SessionClientCore`)의 `+ 강의 추가` 선택창에서 사용됩니다.
- 강의 상세에서 복사한 고유코드로 같은 강의를 다른 폴더에 재사용할 수 있습니다.

## 권한 메모
- 경로 자체는 공개 라우트이지만, 실제 운영에서는 주로 관리자/선생님이 사용합니다.
