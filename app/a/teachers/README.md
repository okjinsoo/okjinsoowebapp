# /a/teachers 페이지 정리

## 페이지 한 줄 설명
관리자 선생님 목록/관리 페이지입니다.

## 화면에서 하는 일
- `+ 선생님 추가` -> [`/a/teachers/new`](./new/README.md)
- 선생님 수정 -> [`/a/teachers/[id]/edit`](./[id]/edit/README.md)
- 선생님 삭제
- `선생님 뷰 열기` -> `/a/tmain`

## 삭제 규칙
- 삭제 대상 선생님에게 배정 학생이 있으면, 확인창에서 안내 후 학생을 "미배정" 처리합니다.
- 그 뒤 선생님을 목록에서 제거하고 서버/로컬을 동기화합니다.

## 데이터
- 목록은 `readTeachersServerRequired()`로 읽습니다.
- 변경은 shared snapshot 기준으로 저장합니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
