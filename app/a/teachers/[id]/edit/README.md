# /a/teachers/[id]/edit 페이지 정리

## 페이지 한 줄 설명
특정 선생님 ID를 수정하는 실제 편집 페이지입니다.

## 흐름
- URL의 `id`로 선생님 데이터를 로딩합니다.
- 로딩 중/없음/수정 가능 상태를 분기해서 보여줍니다.
- 수정 폼(`TeacherEditForm`)에서 값 변경 후 저장합니다.

## 수정 항목
- 이름
- 전화번호
- 이메일
- 업무 시작일

## 저장 동작
- 서버 최신 스냅샷의 선생님 목록에서 동일 id를 찾아 교체 저장합니다.
- 저장 완료 시 `/a/teachers`로 이동합니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
