# /a/tmain/[token] 페이지 정리

## 페이지 한 줄 설명
관리자-선생님 뷰 문맥에서 특정 학생(token) 상세를 여는 페이지입니다.

## 핵심
- `StudentHubCore(role="a", prefix="/a/tmain")`를 사용합니다.
- 기능 자체는 `/a/students/[token]`과 거의 같고, 복귀/연결 경로 문맥이 `tmain` 쪽입니다.

## 제공 기능
- 학생 정보/상태
- 상담/수납/시간표 변경
- 회차 동기화/사물함 정리
- 수업 목록 이동 및 회차 상세 진입

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
