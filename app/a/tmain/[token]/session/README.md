# /a/tmain/[token]/session 페이지 정리

## 페이지 한 줄 설명
`tmain` 문맥에서 특정 학생의 회차 목록을 보는 페이지입니다.

## 동작
- `StudentSessionListCore(role="a", prefix="/a/tmain")`를 사용합니다.
- 예정/지난 수업 리스트, 상담 버튼, 퀵 액션을 제공합니다.

## 용도
- 선생님 운영 화면(`/a/tmain`)에서 학생을 눌렀을 때, 문맥을 유지한 채 회차 리스트를 보는 경로입니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
