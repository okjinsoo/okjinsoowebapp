# /a/tmain 페이지 정리

## 페이지 한 줄 설명
관리자가 "선생님 관점 학생 운영 화면"을 보는 페이지입니다.

## 내부 구조
- `TeacherMainClient(initialRole="a")`를 사용합니다.
- 관리자가 선생님을 선택하면, 그 선생님 학생들의 수업/목록을 볼 수 있습니다.

## 주요 기능
- 오늘 수업 카드
- 다음 수업 카드
- 학생 리스트 카드
- `본인 학생 회차 동기화` 버튼
- `+ 학생 추가` 버튼(`/a/tmain/new`)

## 회차 동기화 버튼 동작(관리자 모드)
- 관리자 계정에서는 직접 생성보다 `pending` 요청 저장을 우선합니다.
- 담당 선생님 계정 로그인 시 정상 재동기화되도록 설계되어 있습니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
