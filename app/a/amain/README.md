# /a/amain 페이지 정리

## 페이지 한 줄 설명
관리자가 전체 운영 상황을 한눈에 보고, 학생/선생님 관리 화면으로 이동하는 대시보드입니다.

## 이 페이지에서 하는 일
- `학생 관리` 버튼으로 [`/a/students`](../students/README.md)로 이동합니다.
- `선생님 관리` 버튼으로 [`/a/teachers`](../teachers/README.md)로 이동합니다.
- `연장 요청` 카드 목록을 보여줍니다.
- `휴회 요청` 카드 목록을 보여줍니다.
- 학생 상태 섹션(연장 필요, 휴회중, 신규 등)을 카드로 보여줍니다.
- 카드 클릭 시 현재 선택 학생/선생님 값을 저장하고 `/a/smain`으로 이동합니다.

## 데이터는 어디서 오나
- `useStudentRegistry()`로 학생/선생님/회차 지표를 받아옵니다.
- 카드 클릭 시
  - `saveCurrentTeacherId()`로 선생님 선택값 저장
  - `saveCurrentStudentToken()`으로 학생 선택값 저장

## 같이 붙어있는 핵심 기능
- `DriveControlPanel`이 포함되어 있어서, 구글 드라이브 본진 폴더를 설정/초기화할 수 있습니다.
- 본진 설정 시 선생님 이메일 공유까지 같이 처리합니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.

## 운영 메모
- 이 화면은 "직접 수정 저장"보다는 "관리 화면으로 빠르게 진입"하는 허브 역할이 강합니다.
