# /a/smain/session 페이지 정리

## 페이지 한 줄 설명
현재 선택 학생의 회차 목록(예정 수업/지난 수업)을 보는 페이지입니다.

## 화면 구성
- 위쪽: `RoleGateCard` (학생/선생님 선택)
- 본문: `StudentSessionListCore(role="a")`
  - 예정 수업 카드
  - 지난 수업 카드
  - 펼치기/접기
  - 상담 버튼/퀵 액션

## 카드에서 보이는 정보
- 회차 번호
- 날짜/시간
- D-day
- 출결 상태
- 성취도 배지
- 추가 배지(변경, 이월, 마지막 수업 등)
- 상담 배지

## 상담 기능
- 회차별 상담 열기/수정/삭제 가능
- 관리자 권한일 때 휴회 관련 상태 반영까지 처리됩니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
