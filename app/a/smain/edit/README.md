# /a/smain/edit 페이지 정리

## 페이지 한 줄 설명
관리자가 현재 선택 학생의 정보를 수정하는 페이지입니다.

## 진입 방식
- 보통 `/a/smain` 또는 `/a/students`에서 학생 선택 후 들어옵니다.
- 내부적으로 저장된 `current student token`을 읽어 대상 학생을 결정합니다.

## 수정 가능한 항목
- 시작일
- 배정 선생님
- 학생 이름/성별/전화번호/학교/학년/Google 이메일
- 학부모 연락처/부모 구분
- 회차 수(planCount)

## 저장 동작
- 서버 최신 기준 스냅샷을 읽은 뒤 학생/회차를 함께 갱신합니다.
- `pushSharedSnapshot`으로 서버 반영 후 로컬 저장소도 동기화합니다.

## 삭제 동작(관리자 전용)
- 학생 삭제 시 학생 정보 + 회차 + 상담 데이터 + 관련 state key를 함께 정리합니다.
- 삭제 완료 후 `/a/students`로 이동합니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
