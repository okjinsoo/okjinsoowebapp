# /a/smain 페이지 정리

## 페이지 한 줄 설명
관리자가 "현재 선택된 학생 1명"의 상세 화면을 보는 페이지입니다.

## 화면 구조
- 위쪽: `RoleGateCard`
  - 선생님/학생 선택을 바꿀 수 있습니다.
- 아래쪽: `StudentHubCore(role="a")`
  - 학생 기본정보
  - 예정 수업
  - 상담/수납
  - 시간표 변경
  - 회차 동기화/사물함 정리

## 주요 동작
- 학생을 선택하지 않으면 안내 문구를 보여줍니다.
- 학생을 선택하면 학생 허브(상세 관리 화면)가 열립니다.
- 관리자 역할(`a`)이라서 학생 허브의 관리자 기능(연장 요청, 삭제 가능한 상담, 수납 패널 등)을 모두 사용할 수 있습니다.

## 데이터
- `readRosterServerFirst()`로 학생/선생님 목록을 서버 기준으로 읽습니다.
- 선택 상태는 `roleGateStorage`/`teachers` 저장소를 통해 유지합니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
