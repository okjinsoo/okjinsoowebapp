# /a/students 페이지 정리

## 페이지 한 줄 설명
관리자 학생 목록/분류 화면입니다.

## 화면에서 하는 일
- 상단 `관리자 페이지` 버튼으로 `/a/amain` 이동
- `+ 학생 추가` 버튼으로 [`/a/students/new`](./new/README.md) 이동
- 학생 목록을
  - 재학생 리스트
  - 휴회생 리스트
  로 나눠 보여줍니다.

## 카드 클릭 동작
- `학생 메인 열기`: 선택 학생/선생님 저장 후 `/a/smain` 이동
- `학생 수정 열기`: 선택 학생/선생님 저장 후 `/a/smain/edit` 이동

## 데이터 기준
- `readRosterServerFirst()` + `useStudentRegistry()`로 상태를 조합합니다.
- 상태값으로 휴회/연장지연(overdue_extension) 분류가 반영됩니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
