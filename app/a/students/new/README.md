# /a/students/new 페이지 정리

## 페이지 한 줄 설명
관리자가 새 학생을 등록하는 페이지입니다.

## 입력 항목
- 배정 선생님
- 시작일
- 학생 기본정보(이름/성별/연락처/학교/학년/Google 이메일)
- 학부모 연락처
- 주간 수업 요일/시간 규칙
- 회차 수

## 저장 방식
- 서버 최신 스냅샷을 기준으로 학생을 추가합니다.
- 현재 구조에서는 "물리 회차를 대량 생성"하기보다, 규칙 기반 회차 계산을 사용하는 흐름이 중심입니다.
- 저장 완료 후 `/a/students`로 이동합니다.

## 검증
- 이메일 형식, 전화번호, 회차 수, 필수값을 검사합니다.
- 선생님/학생 모드 규칙(관리자 모드에서는 선생님 선택 가능)을 지킵니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
