# /a/students/[token] 페이지 정리

## 페이지 한 줄 설명
URL에 포함된 학생 `token`으로 특정 학생 허브를 바로 여는 페이지입니다.

## 핵심
- `StudentHubCore(role="a", prefix="/a/students")`를 그대로 사용합니다.
- `/a/smain`과 기능은 거의 같고, 차이는 "선택값"이 아니라 "URL token"으로 학생을 고른다는 점입니다.

## 제공 기능 요약
- 학생 기본정보/상태
- 정보 편집, 시간표 변경
- 일반/휴회/연장 상담
- 수업 목록 이동
- 회차 동기화, 사물함 정리
- 수납/환불 패널(관리자)

## 참고
- 현재 코드 기준 상단 복귀 버튼은 `/a/tmain`으로 연결됩니다.

## 권한
- `/a/*` 경로이므로 관리자만 접근 가능합니다.
