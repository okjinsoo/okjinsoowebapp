# /t/tmain 페이지 정리

## 페이지 한 줄 설명
선생님 운영 메인 화면입니다.

## 화면 구성
- `TeacherMainClient(initialRole="t")`
- 로그인 이메일과 같은 선생님을 자동 매칭해 본인 학생을 보여줍니다.

## 주요 기능
- 오늘 수업 카드
- 다음 수업 카드
- 학생 리스트 카드
- `본인 학생 회차 동기화`
- `+ 학생 추가` (`/t/tmain/new`)

## 회차 동기화 버튼
- 현재 로그인 계정에 구글 캘린더 토큰이 있는지 검사합니다.
- 조건이 맞으면 담당 학생 묶음에 대해 재동기화 요청을 보냅니다.

## 권한
- `/t/*` 경로이므로 선생님/관리자 계정이 접근 가능합니다.
