# /t/smain 페이지 정리

## 페이지 한 줄 설명
선생님이 "현재 선택된 학생"의 상세 허브를 보는 페이지입니다.

## 화면 구조
- `StudentMainClient(role="t")` 사용
- 상단 역할 선택 카드(`RoleGateCard`)는 관리자 전용이라 선생님 화면에서는 보이지 않습니다.
- 실제 본문은 `StudentHubCore(role="t")`로 렌더링됩니다.

## 선생님이 할 수 있는 일
- 학생 기본정보 확인
- 시간 변경/일반상담/휴회 요청
- 수업 목록 이동
- 회차 동기화, 사물함 정리
- 수납 기록 확인

## 관리자와 차이
- 연장 요청 버튼은 관리자 전용이라 선생님 화면에는 없습니다.
- 그래도 상담/수업/회차 관련 핵심 기능은 대부분 사용 가능합니다.

## 권한
- `/t/*` 경로이므로 선생님/관리자 계정이 접근 가능합니다.
