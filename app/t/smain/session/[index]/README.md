# /t/smain/session/[index] 페이지 정리

## 페이지 한 줄 설명
선생님이 특정 회차 1개를 상세 관리하는 화면입니다.

## 화면 구성
- `StudentMainSessionDetailBase(role="t")`
- 내부에서
  - `SessionTopBarCore(role="t")`
  - `SessionClientCore(role="t")`
  를 사용합니다.

## 할 수 있는 일
- 회차 상단: 출결/조정/상담/미트
- 학습 본문: 강의 추가/삭제/순서변경, 공지/문제 추가, 필기/풀이 제출

## 학생(role=s) 화면과 차이
- 선생님은 회차 메타 수정과 강의 배치 수정 권한이 있습니다.
- 학생은 같은 화면 구조여도 수정 기능이 비활성화됩니다.

## 권한
- `/t/*` 경로이므로 선생님/관리자 계정이 접근 가능합니다.
