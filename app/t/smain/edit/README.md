# /t/smain/edit 페이지 정리

## 페이지 한 줄 설명
선생님이 현재 선택 학생 정보를 수정하는 경로입니다.

## 현재 연결 구조
- `StudentEditBase(role="t")`를 사용합니다.
- `StudentEditBase` 내부에서 현재 구현상 `StudentEditClient(mode="admin")`으로 연결됩니다.

## 현재 구현 기준 동작 메모
- 선생님 경로지만 관리자형 편집 동작이 일부 보일 수 있습니다.
- 특히 삭제 버튼 노출 등은 실제 운영 의도와 다를 수 있으니 확인이 필요합니다.

## 권한
- `/t/*` 경로이므로 선생님/관리자 계정이 접근 가능합니다.
